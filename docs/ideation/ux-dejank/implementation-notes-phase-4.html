Context
The spec's File Changes row for skills/ideation/SKILL.md says to drop the workflow-example.md line and "add a 'human-facing walkthrough: docs/workflow-example.html' note only if the section's grain fits" — an explicitly delegated judgment call.
Decision

The "Shared references (plugin root)" list enumerates model-consumed reference documents the skill reads during the flow; docs/workflow-example.html is repo documentation no skill instruction ever reads, so listing it there would re-create exactly the kind of dangling, model-facing pointer this phase removes. Alternative
